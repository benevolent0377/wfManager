> A lightweight desktop companion application for **Warframe**, focused on bringing game information, community resources, and player utilities into a single interface.

> **Disclaimer:** Warframe Manager is an independent fan-made project and is not affiliated with or endorsed by Digital Extremes.

---

## Overview

Warframe Manager aims to reduce the need for constant alt-tabbing by consolidating commonly used Warframe resources into a single desktop application.

Built around a modular architecture, the project is designed to grow over time while remaining maintainable, lightweight, and highly customizable.
